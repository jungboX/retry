# 자연어 작업 구조화 스킬

## 목적

이 스킬은 농가의 자연어 일손 요청을 구조화해서 서버가 바로 사용할 수 있는 Job 데이터를 만드는 데 사용합니다.

## 수행하는 일

- 작업 유형, 위치, 날짜, 인원, 임금 등을 추출한다.
- 누락된 값이 있으면 사용자에게 직접 확인을 요청한다.
- 구조화된 JSON만 반환한다.
- 승인이나 상태 변경을 수행하지 않는다.

## 사용 예시

에이전트에게 다음처럼 요청할 수 있습니다.

```text
job-request-structurer 스킬을 사용해서 이 농가 요청을 구조화해줘.
```

## 기대 결과

이 스킬은 Job 생성에 필요한 필드를 가진 JSON을 반환합니다.
