# 후보 추천 스킬

## 목적

이 스킬은 Retry 프로젝트에서 농가 작업 요청에 가장 적합한 구직자를 찾고, 고정 규칙으로 점수를 계산하며, 각 후보가 왜 좋은지 설명하는 데 사용합니다.

## 수행하는 일

- 작업 날짜, 위치, 작업 유형 기준으로 후보를 필터링한다.
- 결정론적 가중치로 구직자 점수를 계산한다.
- 후보별 추천 이유를 평문으로 설명한다.
- 승인이나 상태 변경은 하지 않는다.

## 사용 예시

에이전트에게 다음처럼 요청할 수 있습니다.

```text
candidate-matcher 스킬을 사용해서 이 작업에 맞는 후보를 찾고 점수와 이유를 설명해줘.
```

## 기대 결과

이 스킬은 정렬된 후보 목록과 추천 요약을 반환합니다.
